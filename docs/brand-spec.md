# Prachi Dham brand and interface direction

**Source identity asset:** `apps/web/public/brand/logo.png` (supplied by project; 300 × 314 PNG). The mark reads “PRACHI DHAM — GIR SOMNATH, GUJARAT” and shows a tree with human figures and a lamp. Never redraw or replace it with a generic icon.

**Design read:** Internal operations dashboard for nonprofit staff; warm institutional/data-first; greenfield UI with supplied brand. Visual variance 3/10 (predictable navigation), motion 2/10 (feedback only), density 7/10 (tables and live counts), asset dependence 3/10 (logo anchors identity), brand fidelity 8/10 (forest/cream/gold cues).

**Positioning:** The overview is a data screen viewed at laptop distance; quiet and dependable, not a fundraising landing page. Its cards must fit useful actions without invented data. Mobile collapses navigation rather than shrinking tables into illegibility.

**Tokens:** Forest `#193f36`, deep forest `#123229`, parchment `#f7f5ef`, white `#ffffff`, ink `#1d2e28`, muted `#697a72`, border `#dee6df`, soft green `#e6eee7`, gold `#ad8750`, alert `#a04c43`. Use a humanist serif for headings (Georgia fallback) and a legible sans for UI text (system stack). 8px spacing rhythm; 10–16px radii; soft single-level shadows. State transitions 140–180ms ease-out; no decorative gradients or invented photographic mission imagery.

**External imagery decision:** Search assets were collected before UI creation, but the returned nonprofit images contain visible Unsplash+ watermarks and do not match Prachi Dham's actual activities. None are used. The supplied logo is the only visual identity asset in this internal dashboard.

## Public homepage extension

The public `/` route keeps the supplied logo and the same forest/parchment/gold tokens, but uses a quieter editorial hero and generous whitespace instead of dashboard tables. It is a **review draft**: the verified organization name/location are presented without invented mission, activity photos, impact figures, donation methods or contact details. Navigation and CTA lead only to on-page information and the existing `/staff` login. Third-party Prachi tourism images were not used: they do not establish the foundation's activities and their reuse rights were not confirmed.
