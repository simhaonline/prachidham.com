## Architecture and scope decisions

The explicit user stack (Go, Python, Node/Next/Nest, PostgreSQL with TimescaleDB and pgvector, Valkey, Docker) and own-infrastructure choice take precedence over older attachment proposals for Firebase/Firestore or Vercel. The 51-page SOW itself recommends PostgreSQL/Nest/Valkey. Current Next 15 can be retained for this increment; framework-major upgrades require separate compatibility testing. Razorpay is named as the intended gateway, but the Razorpay connector is **disabled** in this session. Do not create chargeable checkout, pretend payments succeeded, produce tax receipts, or publish a 'Buy now' action without verified merchant credentials, signed webhooks, policies and management approval.

Build now: real database-backed catalog with admin publishing, localized public discovery in Gujarati/Hindi/English, a clearly non-transactional inquiry/cart/request path if feasible, branded favicon/PWA with safe offline handling, tests and self-hosting source. Gate public listings on approved translations, pricing and policy. Future languages are added through a locale registry and translation records, not hard-coded branches. Future releases: provider-backed payment and idempotent webhook engine, reservation/inventory, shipping/returns, approved media, customer identity/portal, CRM, scheduling and other SOW modules.
